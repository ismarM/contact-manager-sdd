# Research: Prenova vmesnika

Odločitve, ki jih izvedba potrebuje. Format: odločitev – razlog.

- **R-01 Viri oblikovanja.** Pravila so `README.md` in `tokens.json` oblikovnega sistema (artifact 3c27f387…, lokalna kopija v scratchpadu nadzornika; sicer `Artifact read`). Žetone (`--k-*`) izvajalec prepiše iz `tokens.json` v `frontend/src/styles/app.css` in jih preslika v `@theme`/shadcn spremenljivke po razdelku *Relation to the code* (`popover` → `k-raised`, `sidebar-accent` → `k-surface`, `destructive-foreground` → `k-on-accent`, `--radius` 0.5rem). Zasloni: `canvas.json` + `*.dc.html` (lokalno samo 6 zaslonov; ostale pri izvedbi z `Artifact read`).
- **R-02 design.md.** Zamenja se z v2 (načela, barve, tipografija, prostor, oblike, gibanje, ilustracije, komponente, zasloni, prepovedi); ohranijo se poglavja o dostopnosti (§10), besedilih (§11), PWA (§12) in implementaciji (§13, posodobljena). Verzija v2; potrdita razvijalca (§7) v PR.
- **R-03 Pisave.** Ostanejo obstoječi lokalni paketi (Atkinson Hyperlegible Next variabilna, Mono). Brez nove odvisnosti in zapisa v `docs/architecture-decisions.md`.
- **R-04 `GET /api/groups` = en seznam.** `GroupService.list` vrne `GroupPage {total, page, size, items[]}`; element = `GroupSummary` + `role`. Filter: `q` (017), `role` (ena vloga, neobvezno), urejanje po naslovu (kolacija `lang`) nato id; `page` je dovoljen vedno (prej samo z `role`). `GroupRepository`: `countGroups(user,q,role)` in `pageGroups(...)` nadomestita `countByRole`/`pageByRole`; `GroupSection(s)` se odstrani. Razlog: platno in README prepovedujeta razdelke po vlogah; stran se bere z istim SQL.
- **R-05 Stanje ni filter.** *Skupine* = nearhivirane (`GET /api/groups`), *Arhivirane* = `GET /api/groups/archived` (brez spremembe, že ploski seznam z vlogo). Čipi so samo vloge; arhivirani zaslon uporablja isto kartico in orodno vrstico. Arhivirani endpoint sprejema več vlog; čip pošlje eno.
- **R-06 Števci.** `useNavCounts`: `GET /api/groups?size=1` (`total`), `GET /api/groups/archived?size=1` (`total`), `GET /api/invitations/count`; trije neodvisni klici, vsak ob napaki brez števca; osveži se ob ustvarjanju, arhiviranju, odarhiviranju, sprejemu/zavrnitvi povabila (obstoječi `refresh`).
- **R-07 Preklopnik skupin.** Isti `GET /api/groups` z `size=100` (največ, obstoječa meja) in `lang`; do 100 skupin v preklopniku; iskalno polje v preklopniku ni v obsegu. Nadomešča `SUMMARY_SIZE` razdelke v `GroupsProvider`.
- **R-08 Preglednica kontaktov.** Zlaganje v kartice po širini **vsebnika** (container query `@container`, prag 640 px), ne okna. Plošča podrobnosti: `position: sticky` z `max-height` in lastnim pomikom. Gostota: samo privzeta `--k-row-h` (56 px).
- **R-09 Ilustracije.** Lastne SVG komponente v `shared/ui/illustrations/` (črtna risba kartoteke, barve iz žetonov, `aria-hidden`); brez rastrskih slik in omrežja. Počasen premik vzorca na pozdravni ploskvi je CSS animacija, izklopljena pri `prefers-reduced-motion` in `document.hidden` (FR-020-03).
- **R-10 Skupni pomočniki za teste.** `frontend/src/test/names.ts` (dostopna imena iz prevodov) in `e2e/tests/support/nav.ts` (odprtje skupine prek preklopnika/Skupin, glavna navigacija); obstoječi testi, ki so odpirali skupino prek stranskega seznama, uporabijo pomočnika.
