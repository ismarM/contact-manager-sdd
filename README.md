# Contact Manager SDD

Multi-tenant contact management application developed
using Spec-Driven Development (SDD).

## Tech Stack
- Backend: Spring Boot (Java 21)
- Frontend: React + TypeScript (responsive, PWA, WCAG 2.2 AA)
- Database: PostgreSQL
- Authentication: Firebase (identity only)
- Authorization: Custom, per-group roles (OWNER / MEMBER) stored in PostgreSQL
- Excel: export to `.xlsx`
- SDD: GitHub Spec Kit
- AI Agent: Claude Code
