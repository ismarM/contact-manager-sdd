# Contact Manager SDD

Multi-tenant contact management application developed
using Spec-Driven Development (SDD).

## Tech Stack
- Backend: Spring Boot
- Frontend: React + TypeScript
- Database: PostgreSQL
- Authentication: Firebase
- Authorization: Custom
- SDD: GitHub Spec Kit
- AI Agents: Codex and Claude Code
